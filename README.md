# 잭팟 삼국지 (가제)

슬롯머신으로 병사를 찍어 내고, 뽑기로 모은 장수에게 붙여서, 삼국지 명장면 10개를 막아 내는 **한 시간짜리 B급 오토배틀 디펜스**.

- **병사 슬롯** — 군자금으로 돌려 충원 · 훈련 · 병법 카드를 받고 부대에 끌어다 놓는다
- **등용 슬롯** — 명성으로 장수를 뽑는다. 판에서 져도 장수는 남는다
- **전투** — 배치 칸에 부대를 놓으면 나머지는 자동. 장수 원판이 병사를 이끌고 적 무리를 마중 나가고, 적장과 맞닿으면 일기토
- **스테이지** — 황건적의 난(184)부터 오장원(234)까지 실제 전투 10개

## 실행

ES Modules 라 `file://` 로는 안 열린다. 로컬 서버로 띄운다(Python 3 만 있으면 된다).

```
python serve.py 8790
```

→ 브라우저에서 `http://localhost:8790/index.html` (Windows 는 `start.bat` 이 서버를 띄우고 브라우저까지 연다)

## 폴더

| 자리 | 내용 |
|---|---|
| `src/` | 게임 — `game_logic/`(순수 로직 · 시드 RNG) · `ui/`(DOM · 캔버스) · `data/`(CSV · 수치의 원본) · `assets/art/` |
| `docs/` | 기획(`GAME_DESIGN.md`) · 아트(`ART.md`) · 개발(`DEV.md`) |
| `tools/` | 그림 발주 · 자르기 · 웨이브 초안 · 밸런스 스윕 |

## 검증

```
node src/dev/run_tests.js      # 로직 단정 + 그림 파일
node src/dev/run_sim.js 6 --log  # 자동 플레이어로 처음부터 엔딩까지
```

그림은 전부 Codex(ChatGPT)의 이미지 생성으로 뽑았다 — 절차는 [docs/ART.md](docs/ART.md).
