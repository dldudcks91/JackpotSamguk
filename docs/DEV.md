# 잭팟 삼국지 — 개발

## 1. 구조

무빌드 웹 — ES Modules + DOM/CSS + 캔버스 하나, 서버 없음(정적 파일), CSV, LocalStorage. `game_logic/` 은 엔진 이식을 염두에 둔 순수 모듈이다.

| 모듈 | 하는 일 |
|---|---|
| `game_logic/rng.js` · `csv.js` | 시드 RNG(mulberry32 · `deriveSeed`) · CSV 파서 (TheSevenSimulationRPG 에서 가져옴) |
| `game_logic/data.js` | CSV 행 → `data`(장수 · 계략 · 테크 갈래 · 스테이지+웨이브 · 인연 · 슬롯 그림) |
| `game_logic/slot.js` | 병사 슬롯(3×3 · 줄 8 · 時 와일드 · 잭팟) · 등용 슬롯(릴 3 · 점수 합 → 등급 · 桃 셋 = 도원결의) — 결과 계산만 |
| `game_logic/stats.js` | 파생 수치 한곳: 돌파 · 정원 · 장군직 · 훈련 · 테크 보정 · 인연 · 보스/적/전차 수치 |
| `game_logic/battle.js` | 오토배틀 `BattleSim` — 고정 간격 `step(dt)` · 이벤트 목록(`events`) · `result()` · 대형 `formation` · `squadLayout`. 유닛은 셋으로 움직인다: **이끄는 이**(장수 · 부장 · 보스 — `actLeader`: 적을 골라 행군 · 교전 · 일기토 `tryDuel`) · **딸린 병사**(`actMember`: 교전 중이면 이끄는 이 곁의 적, 아니면 대형 자리 = 이끄는 이 + `ox, oy`) · **혼자**(`actFree`: 복병 · 용병 · 부장이 성에 닿아 남은 병사). 부장이 쓰러지면 `scatter` → `flee` |
| `game_logic/run.js` | 한 판: 스핀 · 카드 놓기(`canApply` · `applyCard`) · 배치 · 전투 시작/정산 · 명성 계산 |
| `game_logic/meta.js` | 판 밖: 새 게임 · 세이브 읽기(검증) · 등용 · 판 정산 · 엔딩 |
| `ui/main.js` | 부팅 · 한 장(1600×900) 배율 · 화면 전환(타이틀 · 군영 · 전투 · 엔딩) |
| `ui/hub.js` | 군영 — 출정(스테이지 카드 · 편성 창) · 등용(릴 연출) · 장수록 · 도움말 |
| `ui/battle_view.js` | 전투 화면 — 슬롯 연출 · 카드 끌어 놓기/눌러 고르기 · 테크 갈래 창 · 배치 끌기 · 전투 루프(보간) · 웨이브 정산 · 판 결과 |
| `ui/field.js` | 캔버스 — 배경 · 배치 칸 · 졸병 그림(편 색 입힘 · y 순 · 움직이는 쪽을 봄 · 걸을 때 통통 · 쓰러짐 · 도망치며 흐려짐) · 장수 얼굴 원판 · 적 부장 원판(스테이지 색 · 將 · 깃발) · 이펙트(계략 외침 · 고리 · 띠 · 불 지대 · 벼락 · 일기토 · 무리 흩어짐) |
| `ui/art.js` | 그림 경로 · 미리 읽기 · 장수 얼굴 토큰(`faceToken`) · 졸병 그림 굽기(`soldierSprite` — 바탕 + 군복 층 × 편 색, 적은 좌우 뒤집기) |

### 결정성
- 판 씨앗 = `deriveSeed(meta.seed, 7000 + counters.run)` · 스핀 n 번째 = `deriveSeed(run.seed, 1000 + n)` · 전투 n 번째 = `deriveSeed(run.seed, 5000 + n)` · 등용 = `deriveSeed(meta.seed, 100 + counters.recruit)`
- 같은 시드면 같은 전투 — 단정 「전투 — 같은 시드면 같은 결과」
- `ui/` 의 릴 굴림 장식만 `Math.random` 을 쓴다(결과는 이미 정해진 뒤다)

### 세이브
`localStorage['jackpot_samguk_save_v1']` = `meta` JSON(`v` · `seed` · `fame` · `heroes{id:{dupes}}` · `cleared` · `counters` · `stats` · `ending`). 판 도중 상태는 저장하지 않는다(판이 몇 분짜리라서). 편성 기억 · 속도는 `jackpot_samguk_pref_v1`.

## 2. 검증

| 무엇 | 어떻게 |
|---|---|
| 로직 단정 22개 + 그림 파일(초상 · 배경 · 아이콘 · 졸병) | `node src/dev/run_tests.js` (브라우저: `dev/test.html`) |

| 밸런스 | `node src/dev/run_sim.js 6 --log` · `sh tools/sweep.sh "--recruit_cost=120 ..."` — 자동 플레이어로 엔딩까지 |
| 화면 흐름 | Playwright(anaconda python · `channel='msedge'` · **PowerShell 에서**) — 2026-10-12 에 새 게임 → 등용 → 출정 → 슬롯 → 카드 드래그 → 배치 드래그 → 전투 → 웨이브 정산 · 늦은 판(장수록 · 도움말 · 5연속 등용 · 테크 갈래 창 · 보스 등장 · 패배) · 10스테이지 승리 → 엔딩까지 콘솔 오류 0 |

개발용 고리: `window.__app`(data · meta · go) · `window.__battle`(run · sim · `finishWave()` = 지금 웨이브를 단숨에 끝까지 — 게임 안의 「결과만 ▶▶」 버튼도 같은 일을 한다). 브라우저에서 `import('./dev/autoplay.js')` 로 자동 준비(`autoPrep`)도 부를 수 있다.

### 자동 플레이어 (`dev/autoplay.js`)
- 준비: 군자금이 되는 만큼 최대 6번 돌리고, 카드는 충원 → 빈자리 큰 부대 · 훈련 → 병사 많은 부대 · 병법 → 전공 높은 부대(갈래는 전공 홀짝)
- 편성: 등급 · 돌파 · 스탯 합 순 상위 N · 배치는 기본 칸 그대로(사람보다 배치를 못 쓴다)
- 판 사이: 명성이 되는 만큼 등용
- 시간 견적 = 전투 시간 ÷ 2(기본 속도 ×2) + 준비 12초 + 스핀당 2.5초 + 판 사이 60초

## 3. 밸런스 — 2026-10-12 결과 (장수가 이끄는 부대 전투)

시드 12개 · 처음부터 엔딩까지:

| 지표 | 값 |
|---|---|
| 엔딩까지 | 평균 53분 · 중앙값 51분 (42 ~ 72) — 전투를 ×2 로 본다고 셈 |
| 출정 횟수 | 평균 12.1번 (10번이면 전승) |
| 첫 시도 승률 | 1:100 · **2(여포):42** · 3:92 · 4:83 · 5:92 · 6:100 · 7:92 · **8(관우):75** · 9:92 · **10(제갈량):75** |
| 웨이브 한 번 | ×1 기준 평균 28 ~ 35초(가장 긴 웨이브 50 ~ 90초) · 기본 ×2 면 15초 안팎 |
| 일기토 | 웨이브당 0.2 ~ 2.3번 — 앞쪽 스테이지에 잦고, 궁병이 멀리서 정리하는 뒤쪽은 드물다 |

거쳐 온 길 (전부 `balance.csv` · `stages.csv` 손잡이):
1. 처음 값 — 전 스테이지 첫 시도 승리 · 47분. 적이 한 줄로 졸졸 와서 하나씩 잡혔다
2. 적이 **무리 지어**(`enemy_groups` · `group_jitter`) 오게 + 적 수 2배(`gen_waves.py COUNT_MULT`) + 훈련 폭 축소(`train_bonus`) → 아군 병사가 웨이브마다 깎이기 시작
3. **보스가 성에 닿으면 패배**(`leak_boss` > 성 체력) — 전에는 보스가 성을 걸어 들어가도 「승리」였다
4. 난이도가 보스 계략에 쏠림(여포 광역 · 황충 저격 → 장수가 쓰러져 부대 붕괴 · 제갈량 화공) → 스테이지별 `boss_hp` · `boss_dmg` · `hp_mult` 로 고름 · 적 원소의 「사세삼공」은 용병을 부르게
5. 명성이 너무 빨리 쌓여 중반에 장수 15명 → 등용 값 120 · 새 게임 명성 240
6. 전투를 **장수 원판이 병사 대형을 이끄는 방식**으로 갈았다(사용자 지시) — 적도 부장이 이끄는 무리 · 부장이 쓰러지면 무리가 도망 · 일기토 · 행군 배율(`march_mult`) · 병사 크기 `soldier_radius` 11 → 6. 그대로면 조금 쉬워져서(마지막 스테이지 첫 시도 92%) `enemy_hp_mult` 1 → 1.12

### 알려진 쏠림
- 자동 플레이어 기준으로 3 ~ 7 · 9스테이지는 쉽다(첫 시도 83 ~ 100%). 사람은 카드 운용이 덜 정확해서 더 어려울 것으로 보지만 실측은 없다
- 결과가 「깔끔한 승리」 아니면 「보스가 성에 닿아 패배」로 갈리는 편이다 — 일반 웨이브의 성 체력 손실이 드물다
- 뒤쪽 스테이지는 궁병 장수(제갈량 · 주유 …) 부대가 적 무리를 멀리서 정리해 맞붙는 장면 · 일기토가 줄어든다
